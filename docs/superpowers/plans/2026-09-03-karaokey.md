# Karaokey Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a sideloaded Fire Stick Android TV app that displays synced lyrics while controlling Spotify playback and accepting guest song requests via a local phone web UI.

**Architecture:** Kotlin Android TV app with Jetpack Compose for TV, embedded Ktor HTTP/WebSocket server for guest phones, Room SQLite for party queue, Spotify Web API for search/playback, LRCLIB for lyrics. Audio plays via Spotify app on Fire Stick (Connect controller model).

**Tech Stack:** Kotlin, Jetpack Compose for TV, Ktor 2.x, Room, OkHttp, EncryptedSharedPreferences, vanilla JS guest UI

## Global Constraints

- minSdk 25, targetSdk 34, ABI armeabi-v7a + arm64-v8a
- Personal sideload only; Spotify Premium required
- No vocal filtering; no Spotify Jam API
- Guest enqueue via phone browser on same Wi-Fi (port 8080)
- Host Spotify OAuth; guests need no Spotify account
- Lyrics from LRCLIB with LRC sync fallback to plain text
