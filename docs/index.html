Karaokey

Fire Stick karaoke for any Spotify song. Build it with your own Spotify Developer credentials, connect a Premium account, and let guests add tracks from their phones.

Get the source on GitHub Add credentials and build

How a party works

  1. You sideload the APK on a Fire Stick.
  2. Karaokey asks the host to log in with Spotify Premium.
  3. Guests scan a QR code on the TV and search from a phone browser. They do not need Spotify.
  4. The TV shows synced lyrics. Audio plays from the Spotify app on a computer.

Add your credentials, then build

Karaokey does not include API keys. Create a free app in the Spotify Developer Dashboard, then put the values in android/local.properties before you compile.

sdk.dir=/path/to/Android/Sdk
SPOTIFY_CLIENT_ID=your_client_id
SPOTIFY_CLIENT_SECRET=your_client_secret
SPOTIFY_REDIRECT_URI=https://YOUR_USERNAME.github.io/karaokey/callback/

Register that same redirect URI on the Spotify app. If you do not want to host a callback yourself, use https://karaokey.ikomex.nl/callback instead.

Build and install

cp android/local.properties.example android/local.properties
# edit credentials and sdk.dir

cd android
./gradlew assembleDebug

adb connect <fire-stick-ip>:5555
adb install -r app/build/outputs/apk/debug/app-debug.apk

On the Fire Stick, enable Developer Options, ADB debugging, and apps from unknown sources. After install, open Karaokey, tap Connect Spotify, and scan the QR code on the same Wi-Fi.

This GitHub Pages site

Enable Pages on the repository (Settings → Pages → Deploy from branch → /docs). Then this page is your public intro, and /callback/ can be the Spotify redirect URI.

Vocal filtering, if you want it, runs on the computer that plays Spotify. See audio-filter/README.md in the repository.
